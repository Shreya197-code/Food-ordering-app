# 🍔 Food Ordering App

A modern food ordering web application built using React.  
It allows users to browse restaurants, explore menus, and navigate seamlessly using client-side routing.

---

## 🚀 Features

- 🔎 Browse restaurants and food items
- 🔄 Client-side routing (React Router)
- ♻️ Reusable components
- ⚡ Fast and responsive UI
- 🔍 Search functionality

---

## 🛠️ Tech Stack

- React
- JavaScript (ES6+)
- CSS
- Parcel (Bundler)
